#### Project Overview

The **Heart Disease Prediction App** is an interactive data application built in **R** that predicts the likelihood of heart disease based on user-provided health indicators.  
In addition to risk prediction, the app generates **personalized lifestyle recommendations** aimed at improving heart health.

The project demonstrates how data analysis and predictive modeling can be translated into a practical, user-facing application.

---

#### Application Features

- Predicts heart disease likelihood based on medical and demographic inputs
- Provides personalized lifestyle recommendations tailored to the prediction results
- Interactive user interface for entering health-related factors

---

#### Data & Inputs

The application uses health-related features such as:
- Age
- Sex
- Chest pain type
- Blood pressure
- Cholesterol level
- Fasting blood sugar
- Maximum heart rate
- Exercise-induced angina

These inputs are processed to generate predictions and recommendations.

---

#### Modeling & Logic

- Data preprocessing and feature handling implemented in **R**
- Predictive logic based on statistical / machine learning techniques
- Model output translated into an interpretable prediction for end users
- Conditional logic used to generate personalized lifestyle recommendations

---

#### Tools & Technologies

- **R**
- **Shiny** – Interactive web application framework  
- **tidyverse** – Data manipulation  
- **ggplot2** – Supporting visualizations

---

#### Outcome

The final result is a functional web application that:
- Allows users to assess heart disease risk
- Translates analytical results into actionable health recommendations
- Demonstrates the ability to move from data analysis to real-world application
